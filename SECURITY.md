## Reporting a Vulnerability

We take the security of `mcp-doctor` and the Model Context Protocol ecosystem very seriously.

If you discover a security vulnerability in `mcp-doctor`, or a prompt-injection evasion technique in our audit rules, please **do not** open a public issue.

Instead, please report it via one of the following channels:

- **Email**: `bakhtiyor.aminzoda@gmail.com`
- **GitHub Security Advisory**: Submit a private advisory at [https://github.com/bakhtiyor-aminzoda/mcp-doctor/security/advisories](https://github.com/bakhtiyor-aminzoda/mcp-doctor/security/advisories)

### What to include in your report:
1. Description of the vulnerability or evasion pattern.
2. Steps to reproduce or proof-of-concept MCP server code.
3. Potential impact on autonomous agents or hosts (e.g. Claude Desktop).

We will acknowledge receipt within 48 hours and work with you on a resolution before any public disclosure.
